# בוט Discord

## הפעלה

1. ב-Discord Developer Portal בטלו את הטוקן הישן שנחשף בקובץ הקודם, צרו טוקן חדש והעתיקו אותו.
2. שכפלו את `.env.example` לקובץ בשם `.env` והחליפו את הערך של `DISCORD_TOKEN` בטוקן החדש. אל תשתפו את הקובץ ואל תעלו אותו ל-Git.
3. התקינו חבילות עם `npm install` והפעילו עם `npm start`.
4. הפעילו רק מופע אחד של הבוט. הקוד יוצר נעילת הפעלה וידחה ניסיון להפעיל עותק נוסף; עצרו את התהליך הישן עם `Ctrl+C` לפני הרצה מחדש.
5. ב-Developer Portal הפעילו את **Server Members Intent** ואת **Message Content Intent**.
6. תנו לבוט הרשאות לצפות בערוצים, לשלוח הודעות ולהטמיע קישורים. להפעלת כל הלוגים עליו להיות מסוגל לצפות גם בערוצים שעליהם רוצים לקבל לוגים. הציבו את תפקיד הבוט מעל תפקידי הוותיקים, החנות ורמות ה-XP.

הגדרות, XP, משתתפי משחקים ומידע על חברים נשמרים בקובץ `bot-data.json` ונשארים לאחר הפעלה מחדש. שמרו גיבוי של הקובץ הזה; הוא מוחרג מ-Git.

## פקודות לכל המשתמשים

הקידומת הראשונית היא `!`, וניתן לשנות אותה באמצעות `!config prefix`.

| פקודה | תיאור |
| --- | --- |
| `!help` | רשימת פקודות |
| `!ping` | זמן תגובת הבוט |
| `!server` | פרטי השרת |
| `!user [@משתמש]` | פרטי משתמש |
| `!avatar [@משתמש]` | קישור לתמונת פרופיל |
| `!v [@משתמש]` | ותק בשרת; אחרי חצי שנה מוענק רול הוותיקים שהוגדר |
| `!h <סיבה>` | קריאה לצוות עם סיבה, עם הגבלת שימוש של פעם בדקה |
| `!level` / `!rank` / `!balance` | XP ורמה |
| `!leaderboard` | עשרת חברי השרת המובילים |
| `!shop` | חנות ה-XP |
| `!roll [צדדים]` | הטלת קובייה |
| `!poll שאלה | אפשרות 1 | אפשרות 2` | סקר עם 2 עד 5 אפשרויות |

## פקודות למנהלים

- `!config` מציג את אפשרויות ההגדרה: קידומת, צבע, רול צוות, ערוץ לבקשות עזרה, רול ותיקים, ערוץ והודעת עליית רמה וטווח/תדירות XP. אפשר להסיר רול צוות או ותיקים באמצעות `off`.
- `!config levelchannel #ערוץ` מגדיר לאן נשלחות הודעות עליית הרמה; `!config levelchannel off` מחזיר לשליחה בערוץ שבו המשתמש כתב.
- `!config levelmessage <טקסט>` משנה את הודעת עליית הרמה. אפשר להשתמש ב-`{user}`, `{level}` ו-`{xp}`. לדוגמה: `!config levelmessage מזל טוב {user}! הגעת לרמה {level} עם {xp} XP`.
- `!leveltest [@משתמש]` שולח תצוגת בדיקה של הודעת עליית רמה לערוץ שהוגדר, בלי לשנות XP או רמה. הפקודה זמינה למנהלים בלבד.
- מערכת הלוגים: `!logs channel #ערוץ` בוחר ערוץ לוגים; `!logs test` שולח הודעת בדיקה; `!logs list` מציג את כל סוגי האירועים; `!logs enable <שם>` ו-`!logs disable <שם>` מפעילים או מכבים אירוע בנפרד; `!logs channel off` מכבה את המערכת. האירועים מופעלים כברירת מחדל, למעט לוגי תגובות (כדי למנוע הצפה); ניתן להפעיל אותם ידנית.
- האירועים כוללים חברים (הצטרפות/עזיבה/עדכון/בוסט), מחיקת/עריכת הודעות, מחיקה מרובה, תגובות ונעיצות, ערוצים, רולים, חסימות, פעילות קולית, אימוג׳ים ומדבקות, שרשורים, הזמנות, אירועים ובמות, פעולות וכללי AutoMod, אינטגרציות, Webhooks ועדכוני שרת. `!logs list` מציג את מזהה ההגדרה המדויק לכל אירוע, לדוגמה `!logs disable voice`.
- הלוגים נשלחים ב-Embeds קומפקטיים בצבע ובאימוג׳י מותאמים לסוג האירוע. מחיקות ועריכות מציגות תוכן הודעה כאשר Discord העביר אותו לבוט; הודעות ישנות או חלקיות עשויות שלא לכלול את התוכן. אירועי AutoMod דורשים שהבוט יתחבר עם intents של Auto Moderation; הם כבר מוגדרים בקוד.
- פאנל רולי התראות אישי: הגדירו את הרולים עם `!notifyroles role events @רול`, `!notifyroles role giveaways @רול` ו-`!notifyroles role announcements @רול`, ואז פרסמו עם `!notifyroles setup #ערוץ`. הכפתורים מעניקים או מסירים את הרול בלחיצה, והחברים יכולים לבחור כל שילוב. אפשר לערוך את הכותרת, התיאור והצבע באמצעות `!notifyroles title <טקסט>`, `!notifyroles message <טקסט>`, `!notifyroles color #RRGGBB`. `!notifyroles setup` מעדכן את הפאנל במקום ליצור כפילויות. דרושה לבוט הרשאת **Manage Roles** ותפקיד הבוט חייב להיות מעל שלושת הרולים.
- מערכת ה-Welcome שולחת ברכה מעל Embed מעוצב עם תמונת המשתמש, פרטי הצטרפות וטיפים. אפשר לערוך אותה בפקודות: `!welcome channel #ערוץ`, `!welcome title <טקסט>`, `!welcome greeting <טקסט>`, `!welcome message <טקסט>`, `!welcome tips <טקסט>`, `!welcome color #RRGGBB`, `!welcome test`, `!welcome off`. בטקסטים אפשר להשתמש במשתנים `{user}` (תיוג המצטרף), `{username}` (שם התצוגה), `{server}` (שם השרת), `{members}` (מספר החברים), `{joined}` (זמן ההצטרפות היחסי) ו-`{created}` (תאריך יצירת החשבון). כדי להפריד טיפים לשורות, כתבו `\n`. לדוגמה: `!welcome greeting 👋 {user} ברוך הבא ל-{server}!` ואז `!welcome test` לתצוגה מקדימה.
- `!tickets preset` מתקין פאנל עברי מסודר עם חמש אפשרויות: 🚨 דיווח על שחקן, 👑 פנייה להנהלה, 📝 נושא אחר, 🤝 פארטנר, 🆘 עזרה כללית. הפקודה מקבלת גם ערוץ, למשל `!tickets preset #טיקטים`, ומעדכנת את הפאנל הקיים במקום ליצור עותק.
- `!tickets setup [#ערוץ]` מפרסם או מעדכן את הפאנל באותו ערוץ במקום ליצור עותק חדש בכל הרצה; הוא מסיר כפילויות ישנות שנמצאות ב-100 ההודעות האחרונות. לאחר בחירת נושא נפתח טופס סיבה והנושא מוצג בערוץ הפרטי.
- `!tickets category #קטגוריה|off`, `!tickets staff @רול1 @רול2` מגדיר כמה רולים כמורשי צוות בטיקטים. אפשר גם לנהל רול בנפרד עם `!tickets staff add @רול` או `!tickets staff remove @רול`, לראות אותם עם `!tickets staff list` ולהסיר את כולם עם `!tickets staff off`. כל הרולים יקבלו גישה לערוץ הטיקט ויוכלו לסגור אותו.
- `!tickets title טקסט`, `!tickets message טקסט`.
- עריכת אפשרויות ה-dropdown: `!tickets option list`, `!tickets option add <id באנגלית> <אימוג׳י או -> <שם> | <תיאור>`, `!tickets option edit <id> <אימוג׳י או -> <שם> | <תיאור>`, `!tickets option remove <id>`. דוגמה: `!tickets option add billing 💳 תשלומים | שאלות על רכישות`. אחרי שינוי האפשרויות הרץ `!tickets setup` כדי לפרסם פאנל מעודכן.
- `!staffapply setup` מפרסם פאנל בחינות צוות עם כפתור 📋. בלחיצה נפתח טופס מועמדות, ולאחר השליחה נפתח ערוץ פרטי למועמד/ת ולצוות עם התשובות. הגדר קודם רול צוות עם `!config staff @רול`; ניתן להשתמש בקטגוריה שהוגדרה עם `!tickets category #קטגוריה`. עריכת הפאנל: `!staffapply title טקסט`, `!staffapply message טקסט`, `!staffapply button טקסט`.
- `!levelrole <רמה> @רול` מגדיר רול שמוענק בהגעה לרמה; `!levelrole remove <רמה>` מסיר אותו.
- `!shopadd @רול <מחיר XP> <שם>` ו-`!shopremove <מספר>` עורכים את חנות ה-XP.
- חנות ה-XP מציגה את הרולים והמחירים ברשימה, עם dropdown לבחירת רול. הבחירה מציגה למשתמש פרטים, יתרת XP וכפתור אישור; ה-XP יורד רק לאחר שהרול הוענק בהצלחה.
- `!shopchannel #ערוץ` בוחר את ערוץ פרסום החנות, ו-`!shopchannel off` מבטל את הבחירה. לאחר מכן מנהל מפרסם או מעדכן את הפאנל עם `!shop post`; הפקודה שומרת את מזהה ההודעה ומעדכנת את אותו פאנל במקום ליצור עוד אחד. היא מאחדת גם עותקים קודמים של פאנל החנות בהודעות האחרונות בערוץ. `!shop` מקשרת לפאנל הקבוע אחרי שפורסם.
- `!shopconfig title טקסט`, `!shopconfig message טקסט`, `!shopconfig button טקסט` עורכות את כותרת החנות, ההסבר וטקסט ה-dropdown. לאחר עריכת העיצוב הרץ `!shop post` כדי לפרסם פאנל מעודכן.
- `!xpadd @משתמש <כמות>` מוסיף XP.
- `!giveaway <זמן> <פרס>` פותח הגרלה; ניתן להגדיר רול כפרס עם `!giveaway <זמן> @רול [טקסט נוסף]`. בסיום נבחר זוכה אקראי, נשלחת הודעת זכייה חגיגית עם תיוג לזוכה והבוט מעניק לו את הרול אוטומטית. בדקו שלבוט יש הרשאת **Manage Roles** ושתפקיד הבוט גבוה מרול הפרס. אם לא ניתן להעניק את הרול, ההודעה תציין זאת.
- `!drop <זמן> <פרס>` פותח דרופ, והלוחץ הראשון על הכפתור זוכה. הזמן נכתב לדוגמה `30s`, `10m`, `2h` או `1d` (בין 10 שניות ל-30 ימים). לדרופ XP אוטומטי השתמשו למשל ב-`!drop 30s 500 XP` (1 עד 1,000,000 XP); הזוכה הראשון יקבל את ה-XP, ורמות/רולי רמה יעודכנו בהתאם. הפקודה מחזירה מזהה לסיום מוקדם עם `!enddrop <מזהה>`.
- `!giveawayconfig` מציג פקודות לעריכת כותרת ההגרלה, התיאור, כפתור ההרשמה, הודעת הזכייה והצבע (`#RRGGBB`). אפשר גם לאפס עם `!giveawayconfig reset`. בהודעות ניתן להשתמש במשתנים `{user}`, `{host}`, `{prize}`, `{role}` ו-`{participants}`. העיצוב מתעדכן גם בהגרלות פעילות.
- `!purge <1-100>` מוחק הודעות אחרונות.
- `!announce #ערוץ <הודעה>` מפרסם הודעה מעוצבת ללא תיוגים לא צפויים.

`!drop <זמן> <פרס>` הוא דרופ לתופס/ת הראשון/ה: הלחיצה הראשונה זוכה ומסיימת אותו. `!giveaway` בוחר זוכה באקראי מבין הנרשמים.

הבוט בודק רולי ותק בעת הפעלה, כל שש שעות, בעת פעילות של משתמש, וגם כשמשתמש מריץ `!v`. תפקיד הוותיקים מוענק לאחר שישה חודשים מתאריך ההצטרפות לשרת הנוכחי. בדיקה תקופתית כוללת חברים שנמצאים ב-cache של Discord.js.
